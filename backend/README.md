# CampusFix backend

Backend Laravel que fornece a interface web Blade/Tailwind, a API REST `/api/v1`, as regras de negócio compartilhadas e o acesso ao único banco MySQL do CampusFix.

Consulte o [README principal](../README.md), [preparação do ambiente](../docs/development-environment.md), [configuração do MySQL](../docs/mysql-development.md), [contrato da API v1](docs/api-v1.md) e [criação segura do primeiro administrador](docs/development/first-admin.md).

Não execute o seeder geral em produção: ele inclui dados de demonstração. Leia [preparação para produção](../docs/production-configuration.md) e [deploy, backup e recuperação](../docs/deployment-backup-recovery.md) antes de implantar.
